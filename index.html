01

USB / UART hardware

The Ferrum CP210x filter targets USB\VID_10C4&PID_EA60. A matching compatible adapter can provide the USB-to-UART transport. VID/PID matching alone does not implement the board protocol or establish full compatibility.

HOSTFerrum driver
USB →
TRANSPORTCP2102N
UART →
BOARD LOGICMCU

Connection

  • Adapter TX → MCU RX
  • Adapter RX → MCU TX
  • Common ground; compatible logic levels
  • UART support for 115200 and 3000000 baud

MCU responsibilities

  • Discovery replies and board metadata
  • Status, acknowledgements and heartbeat
  • Mouse, keyboard, controller or proxy commands
  • Required downstream hardware behavior

The recorded adapter was CP2102N. Ferrum uses receive-timeout request 0x17, documented as CP2102N-only. Older CP2102 adapters and other generic UART cables are not established as compatible. Hardware details ↗

02

Board discovery

The framed discovery exchange reports a board number and firmware version. These fields are stored rather than compared with a fixed secret in the examined discovery routine.

DirectionMessagePurpose
Host → MCUC3 / 11Discovery request and baud transition
MCU → HostC3 / 12Board number + firmware version (two u32LE fields)
Host ↔ MCUC3 / 13Confirmation exchange
Host → MCUAA / 35Configuration after promotion to active transport

Message labels above are not complete packets. Framing, CRC, timing, state and acknowledgements are required. Complete discovery sequence ↗

App and driver checks

Local driver
A disconnected or crashed driver can trigger a blocking UI screen. Discovery, role selection and liveness remain required.
Update server
The three traced HTTP callers request update metadata, a version list and an MSI installer. No online board-authentication requirement was found in those paths.
Unverified
Complete offline app behavior, a live custom-MCU replacement and passage of every Ferrum check have not been demonstrated.

Testing

  1. Download the MSI and verify its SHA-256 against the checksum file.
  2. Install the package on a Windows x64 test machine. Installation changes the system’s drivers and services.
  3. Connect a compatible CP2102N adapter. Check its hardware ID and Ferrum driver attachment.
  4. For board-level testing, connect an MCU implementing discovery, status and the required commands. A bare UART cable does not provide these functions.

The download contains vendor software, not replacement MCU firmware. Private logs, captures, decompiled source and research projects are excluded.
